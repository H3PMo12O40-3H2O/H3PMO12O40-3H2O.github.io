使用说明 / 连不上看这里
浏览器：Android 的 Chrome / Edge / 三星浏览器（自带浏览器、iOS Safari 不支持）。
① 手机"定位服务"必须开启——安卓的蓝牙扫描强制要求定位权限，关着就一个设备都扫不到（这是"没有兼容设备"最常见的元凶）。
页面必须 HTTPS（或 localhost）才能用蓝牙：本页已放在 GitHub Pages 上，直接访问即可。
连接前：先在 nRF Connect 等 App 里断开——BLE 设备一次只能连一个终端，被占用时这里搜不到。
速度：Android 通常协商 MTU 517（约 0.5 秒一张）；Windows 可能卡在 MTU 23（约 10 秒），属正常。
提示：不需要配对（pair），直接连接即可。
位置记录：连接后自动把 GPS 轨迹记录在手机本机（关页面不丢），找车时在④区查看或导出 CSV；勾选"写固件"可做冗余备份。需要定位权限；页面要保持在前台（会自动申请屏幕常亮）。iOS Safari 不支持 Web Bluetooth，iPhone 需要原生 App。
地图链接：默认高德，可在④区切换百度（国内可用，自动做坐标纠偏）。
GPS 超时（code=3）：国内常见——网页定位走手机系统定位服务，无谷歌服务的手机（部分华为/荣耀）或谷歌网络定位被墙时会超时；排查提示会直接显示在④区。
