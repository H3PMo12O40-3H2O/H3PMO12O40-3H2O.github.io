使用说明 / 连不上看这里
浏览器：Android 的 Chrome / Edge / 三星浏览器（自带浏览器、iOS Safari 不支持）。
页面必须 HTTPS（或 localhost）才能用蓝牙： ① 把本页放到任意 HTTPS 静态托管（GitHub Pages 等）；或
② 电脑跑 python -m http.server 8000，手机 Edge 访问 http://电脑IP:8000/ble_viewer.html，并在 Edge 打开 edge://flags/#unsafely-treat-insecure-origin-as-secure 把该源加进白名单。
连接前：先在 nRF Connect 等 App 里断开——BLE 设备一次只能连一个终端，被占用时这里搜不到。
速度：Android 通常协商 MTU 517（约 0.5 秒一张）；Windows 可能卡在 MTU 23（约 10 秒），属正常。
提示：不需要配对（pair），直接连接即可。
